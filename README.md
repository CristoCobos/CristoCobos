### 📑 Statistical Report Generator

A tool developed during my Social Service at UAEH to automate the generation 
of statistical reports from institutional datasets.

The project integrates **data processing, statistical analysis, visualization 
and automated document generation**, reducing repetitive work in the reporting 
process.

**Technologies:** R, dplyr, tidyr, ggplot2, readxl, Sweave, LaTeX

🔗 [View repository](https://github.com/CristoCobos/Generador-de-Reportes)

---

### 🕸️ Pyrameters

A collaborative academic project focused on computational Graph Theory.

The project implements algorithms for calculating graph parameters such as 
**clique number, chromatic number and girth**, using algorithmic techniques 
including backtracking, branch and bound, greedy coloring and BFS.

**Technologies:** Python, NetworkX, Graph Algorithms

🔗 [View repository](https://github.com/or476651-orlando/pyrameters)
